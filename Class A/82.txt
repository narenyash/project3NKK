These considerations made me interested in learning more about cybersecurity.

One of the first security concepts I became familiar with was authentication.

Authentication allows a system to verify who a user is.

For example, a user may log into an application using an email address and password.

However, authentication needs to be implemented carefully.

Passwords should be stored securely rather than as plain text.

Login systems should also consider issues such as repeated failed attempts and session management.

Learning about these concepts made me realise that even a simple login page involves several security decisions.

Another concept that interests me is authorisation.

Authentication and authorisation are related but different.

Authentication determines who the user is.

Authorisation determines what the user is allowed to do.

For example, an application may have administrators, employees, and regular users.

Each role may have different permissions.

A user should not be able to access administrative functions simply by changing something in the frontend.

The backend should enforce permissions as well.

This taught me an important lesson about security.

Security cannot depend only on what the user interface shows.

The server needs to verify important actions independently.

My experience with full-stack development helped me understand this distinction.

When building applications, it is easy to focus heavily on the frontend because it is what users see.

However, the backend is responsible for protecting important operations and data.

A secure system needs both.

Another area that interests me is data protection.

Modern applications collect large amounts of information.

This can include names, contact details, account information, transaction data, and other personal information.

If this information is not protected properly, it can be exposed or misused.

Therefore, developers need to consider security from the beginning of the development process.

I want to learn more about secure data storage, access control, encryption, and secure communication.

Encryption is another topic I find interesting.
