
I am a student with a strong interest in computer science, artificial intelligence, and software development. One area of artificial intelligence that I find particularly interesting is computer vision. Computer vision focuses on enabling computers to understand and analyse images and videos. I became interested in this field because images contain a large amount of information, and teaching computers to interpret that information involves both programming and machine learning.

My interest in computer vision developed as I explored different areas of artificial intelligence. Initially, I was more familiar with software applications and basic machine learning. As I started working with images, I realised that computer vision involves many different problems.

A computer can receive an image as a collection of pixels.

A person can look at the same image and immediately recognise objects, colours, shapes, people, or actions.

For a computer, however, these tasks require mathematical representations and algorithms.

I found this difference interesting and wanted to understand how machines can learn to interpret visual information.

One of the first concepts I learned was image processing.

An image can be represented digitally using pixels.

Each pixel contains information about colour or intensity.

By manipulating these values, software can perform different operations on an image.

Images can be resized, cropped, enhanced, filtered, or transformed.

These operations may appear simple, but they form the foundation of many computer vision applications.

I became interested in understanding how these basic operations are used before more advanced AI models are applied.

Another concept I explored was image classification.

Image classification involves assigning an image to a particular category.

For example, a model could classify images of different types of objects.

This is one of the basic problems in computer vision.

A machine learning model needs to learn patterns from training images and use those patterns to classify new images.

I found this interesting because the model is not simply following a list of manually written rules.

It learns patterns from examples.

This introduced me to the importance of training data.

A computer vision model can only learn effectively if the training dataset contains useful examples.

If the dataset is too small or does not represent real-world conditions, the model may not perform well when given new images.

This made me understand that collecting and preparing data is an important part of AI development.

Another area I find interesting is image preprocessing.

Images collected from the real world can have different sizes, lighting conditions, backgrounds, and levels of quality.

Before training a model, images may need to be resized or normalised.

Other preprocessing techniques can also be used depending on the problem.

This helps create a more consistent dataset.

I found this process useful because it showed me that developing an AI system involves much more than selecting a model.

Another concept I became interested in is convolutional neural networks.

Convolutional neural networks, or CNNs, became important in computer vision because they can learn useful patterns from images.

Different layers can learn different types of features.

Earlier layers may identify simple patterns such as edges.

Later layers can combine these patterns to recognise more complex structures.

I found this concept interesting because it provides a way for a model to gradually build a representation of an image.

Learning about CNNs also helped me understand how deep learning can be applied to visual data.

Another area I explored was object detection.

Classification answers the question of what is present in an image.

Object detection goes further by identifying objects and locating them within the image.

For example, a system could identify several objects and draw bounding boxes around them.

This has many applications.

It can be used in traffic monitoring, security systems, robotics, agriculture, manufacturing, and autonomous systems.

I find object detection interesting because it requires both recognition and localisation.

Another related problem is image segmentation.

Segmentation involves identifying which pixels belong to particular objects or regions.

Instead of simply drawing a rectangular box around an object, the system can identify its exact shape.

This can be useful in medical imaging, autonomous vehicles, agriculture, and industrial inspection.

I find segmentation interesting because it requires a more detailed understanding of the image.

Another application that interests me is medical imaging.

Medical images such as X-rays, MRI scans, CT scans, and other types of images contain information that can be difficult to analyse manually at large scale.

Computer vision models can potentially assist professionals by identifying patterns or highlighting areas that may require attention.

However, medical applications require very high standards of accuracy and validation.

An AI model should not automatically replace professional judgement.

This has made me interested in both the technical and responsible aspects of medical computer vision.

Another area I have explored is image classification for medical applications.

A model can potentially be trained to distinguish between different categories of images.

Another important topic is dataset creation.

Computer vision models require labelled images for many supervised learning tasks.

Labelling can be time-consuming.

For object detection, each object may need to be marked with a bounding box.

For segmentation, individual regions may need to be labelled.

The quality of these labels can affect model performance.

This has made me more interested in the data preparation side of computer vision.

Another challenge is dataset bias.

If the training images do not represent the situations in which the model will be used, performance may decrease.

For example, a model trained mainly on clear daytime images may struggle in low-light conditions.

A model trained on one type of environment may not work equally well in another.

Therefore, datasets need to represent realistic conditions.

I want to learn how researchers evaluate dataset quality.

Another issue is data augmentation.

Training images can sometimes be modified through transformations such as rotation, cropping, or changes in brightness.

These techniques can increase the variety of training examples.

They may help models become more robust.

However, transformations need to be appropriate for the problem.

An unrealistic transformation can make the training data less useful.

I find this balance interesting.

Another area I want to study is transfer learning.
